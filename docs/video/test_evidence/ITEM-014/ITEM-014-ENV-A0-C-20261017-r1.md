## 3.1 D-01 修复记录（验证轮 TEST_FAIL → 修复）

- **缺陷**（VERIFY-ITEM-014.md D-01）：恢复成功后，**完全相同文本**的断流不再触发重建（`attempts` 停在 1、generation 2→2）。
- **根因**：`RecoveryController::tick()` 以 `last_error != last_seen_error_` 文本等值去重；恢复后去重状态未失效，重建清空 `last_error` 后同文本错误被当旧错误跳过。
- **修复**：`tick()` 在 **generation 变化**或 **`last_error` 变空**时清除 `last_seen_error_`；恢复确认路径同样清除。
- **复核**：本轮（r3）注入两次相同文本断流，CAM-01 `attempts=2`、`generation 1→3`、`recovered_generation=3`、`repeat_same_error_recovers=true`，acceptance PASS。
