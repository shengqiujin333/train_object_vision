## 1. 交付边界

- 本 capability 交付**视觉系统与页面状态设计**：颜色语义、字体层级、间距、布局、图标、组件、状态与资源规范，并给出实际需要的页面在正常/空/加载/失败/恢复状态下的视觉定义。
- 不产出桌面运行代码（归 `desktop_app_implementation`），不改变业务判据与报警级别映射（PRD §8.2），不做部署与验收。
- 本轮**未使用图像生成工具**（未注册/未授权）；页面示意为手工编写的可编辑 SVG 线框/示意，**不代表已运行程序，也不是运行截图**。
- 本期视觉范围与交互方案 §0.4 一致：**只覆盖 6 路可见光**，不为红外/模式切换设计可交互控件；NVR 仅以“已登记/未配置”设备卡片呈现，通道映射未提供时不虚构通道号。
- 项目设备工具已禁用，**未执行任何物理测试**；分辨率、屏幕尺寸、输入方式以交互方案 §0.1 的平台判定与 §4.1 显示档位为准（1920×1080 主档 / 1280×720 最低档）。

## 2. 设计决策摘要

1. **深色主题（Dark）优先**：司机室夜间/隧道/强逆光环境，深色底降低眩光与驾驶分心，且让视频画面与红色报警成为最高视觉权重。选择依据为使用环境（专业判断），需现场走查验证眩光表现。
2. **颜色不是唯一编码**：报警级别与摄像头状态一律用"颜色 + 形状/图标 + 文字"三重编码，满足交互方案 §9 与无障碍要求。
3. **信息层级以任务安全为先**：前方主画面与一级报警拥有最高视觉权重（最大面积、最高饱和度、最高 z 轴）；调试信息默认最低权重且司机不可见。
4. **边框分层代替重阴影**：车载屏反光环境下大面积阴影会发灰，改以表面亮度差 + 1px 边框分层，阴影仅用于浮层。
5. **组件面向触控与键盘双输入**：关键目标 ≥44px，焦点环始终可见。
6. **令牌化交付**：所有颜色/字号/间距/圆角/状态色收敛为 `design_tokens.yaml`，实现侧不得散落硬编码色值。

### 3.4 报警级别（三重编码）

| 级别 | 形状字形 | 强调色 | 实底 + 白字 | 对比 | 声音 | 持续 |
|---|---|---|---|---|---|---|
| 一级 | ▲ 实心三角 | `#FF6B6B` | `#C42B1C` | 5.66:1 | 持续至确认 | 直到确认 |
| 二级 | ● 实心圆 | `#F0883E` | `#B45309` | 5.02:1 | 短提示音 | 直到关闭/确认 |
| 三级 | ◆ 实心菱形 | `#E3B341` | `#8A6D00` | 4.92:1 | 无 | 10s 自动消失 |

- 一级横幅允许 ≤1.5Hz 脉冲（上限 3Hz），文字保持稳定不闪。
- 级别文字必须出现（"一级/二级/三级"），形状与颜色仅作冗余强化。
- 报警横幅文本用 `text_on_solid`（白）置于实底；列表/卡片内用级别强调色文字置于 `tint_bg`。

### 3.5 摄像头/流状态色（与交互方案 §7.1 状态机一致）

| 状态 | 文字 | 前景/背景 | 形状 |
|---|---|---|---|
| 在线 LIVE | 在线 | `#3FB950` / `#12261A` | 实心点 |
| 连接中 | 连接中 | `#4C9AFF` / `#12203A` | 转圈 |
| 重连中 | 重连中（含次数） | `#4C9AFF` / `#12203A` | 转圈 |
| 画面冻结 | 画面冻结 | `#E3B341` / `#2A2312` | 雪花 |
| 画面降级 | 画面降级 | `#E3B341` / `#2A2312` | 警告 |
| 离线 | 离线 | `#FF6B6B` / `#331114` | 斜杠 |

> 非"在线"状态的视频格必须叠加半透明占位层并显示最近一帧时间戳；**不得**把旧帧当作实时（交互方案 §7.1）。

### 3.6 成像模式与设备集成状态

- **成像模式位（本期）**：只接可见光。模式位固定显示 `可见光`，以 `neutral` chip（形状=实心点 + 文字）呈现；`红外` 以 `text_disabled` 文字“红外未接入”同列灰显，**不提供任何模式切换控件**（交互方案 §0.4）。不使用红/绿等告警色，避免被误读为异常。
- **设备集成状态**（NVR 等外部设备）：

| 状态 | 文字 | 前景/背景 | 形状 |
|---|---|---|---|
| 探测中 | 探测中 | `#4C9AFF` / `#12203A` | 转圈 |
| 已登记·可达 | 可达 | `#3FB950` / `#12261A` | 实心点 |
| 已登记·不可达 | 不可达 | `#FF6B6B` / `#331114` | 斜杠 |
| 未配置 | 未配置 | `#8B949E` / `#1B2027` | 减号圆 |

- NVR 通道映射未提供时，通道列一律显示 `未配置`（neutral），**不得用猜测通道号或空值冒充已配置**；界面不提供自动修改 NVR 配置的入口。

## 4. 字体系统

- UI 字体栈：`"Noto Sans CJK SC","Source Han Sans SC","WenQuanYi Micro Hei","Noto Sans",sans-serif`（Ubuntu 22.04 车载机可装 Noto CJK）。
- 数值字体栈（时间/帧率/距离/置信度/坐标）：`"Noto Sans Mono","DejaVu Sans Mono",monospace`，启用等宽数字避免跳动。

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| display | 32/40 | 700 | 一级报警标题 |
| h1 | 24/32 | 700 | 页面标题 |
| h2 | 20/28 | 500 | 区块标题 |
| body_lg | 18/26 | 400 | 司机关键文本 |
| body | 16/24 | 400 | 正文/表格 |
| label | 14/20 | 500 | 标签/按钮 |
| caption | 12/16 | 400 | 非关键辅助 |

- 司机可见关键文本下限 16px 等效（1280×720 档），一级报警标题下限 24px 等效。
- 中文长文本按可用宽度换行，最多 2 行后省略并保留 tooltip/详情；禁止压缩字号换行。
- 数字与单位之间保留半个空格（如 `12.4 m`），单位不换行拆分。

## 5. 间距 / 圆角 / 边框 / 层级

- 8px 基础网格；间距阶：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 安全边距：1920×1080 为 24px，1280×720 为 16px。
- 圆角：chip 4 / button 6 / card·panel 8 / modal 12 / pill 999。
- 边框：常规 1px `border`；强调 2px `border_strong`；报警左/上边 3px 级别色。
- 层级（z-index）：视频叠加 10 < 顶栏/导航 100 < 自动弹窗 300 < 报警横幅 400 < 模态 500 < toast 600。
- 浮层阴影按 `elevation` 令牌；面板/卡片不用阴影，只用表面亮度与边框分层。

## 6. 图标与资源规范

- 图标网格 24px，描边 2px，线性风格；状态点/报警级别用实心字形。
- 必需图标集：camera、camera-off、bell、replay-clock、grid-6、cpu-ai、wrench、check、warning-triangle、circle、diamond、play、pause、speed、export、lock、user、clock、thermometer、disk、network、server、minus-circle、chevron-left/right、close、search、filter。
- **授权规则**：优先使用开源许可图标集（Lucide — ISC；Material Symbols — Apache-2.0）或项目自绘 SVG；每个引入图标须在实现侧登记来源与许可，禁止使用未授权素材。
- 图像生成工具未注册/未授权，本设计不使用生成图；若后续使用，必须补可编辑规范与状态，且不得冒充运行截图。
- 页面示意 SVG 为手绘可编辑矢量（viewBox 1920×1080），导出格式 SVG（如需位图，PNG @1x/@2x）；授权来源：本项目自绘。

## 7. 组件库与状态

每个组件给出视觉规格与状态。所有交互态包含 default / hover / pressed / focus / disabled。

### 7.1 按钮 Button

| 变体 | 默认 | 悬停 | 按下 | 禁用 |
|---|---|---|---|---|
| Primary | 底 `accent`，字白 | `accent_hover` | `accent_pressed` | 底 `neutral_bg`，字 `text_disabled` |
| Secondary | 透明底，1px `border_strong`，字 `text_primary` | 底 `surface_hover` | 底 `surface` | 字 `text_disabled` |
| Danger | 底 `#C42B1C`，字白 | 提亮 8% | 压暗 8% | 底 `neutral_bg` |
| Ghost | 无底，字 `link` | 底 `surface_hover` | 底 `surface` | 字 `text_disabled` |

- 尺寸：lg 44px、md 36px、sm 32px；正文 16px（lg）/14px（md、sm）。
- 焦点：2px `focus_ring` 外环 + 3px 半透明光晕，始终可见（键盘与触控均保留）。
- 图标+文字按钮图标在前，间距 8px；长按无隐藏操作。

### 7.2 状态徽标 StatusChip

- 结构：形状字形(12px) + 文本(label 14px)，底 `*_bg`，文字 `*_fg`，圆角 chip，内边距 4×8。
- 未知/不适用用 neutral，不用空白。

### 7.3 报警卡片 AlarmCard

- 左缘 3px 级别色；左上级别徽标（形状+文字）；主行=类型 + 来源摄像头；次行=时间(mono) + 距离/置信度；右下操作 [确认] [查看回放]。
- 未确认：级别色描边；已确认：描边转 `border`，级别徽标保留但降饱和至 60%。
- 录像不可用：卡片内显著黄色提示条"录像不完整/不可用"（PLY-008）。

### 7.4 报警横幅 AlarmBanner（全局）

- 高度 64px，实底级别色，白字；左侧形状字形 + 级别 + 类型 + 摄像头 + 时间；右侧 [确认] [查看回放]。
- 一级：常驻，1.5Hz 脉冲边框；确认后降级为可关闭，声音停止。
- 多条同时：只显示最高级一条，其余折叠为"+N"角标，点击展开列表（不刷屏，ALM-005）。
- 位置：顶部状态条下方，跨全宽；不得覆盖前方主画面中央区（交互方案 §4.2）。

### 7.5 摄像头格 CameraTile

- 画面 16:9（左右侧）/ 4:3 或 16:9（前方，随源比例 letterbox，保持不拉伸）。
- 左上：位置名（前/左/右/车顶/车底/司机室）；右上：状态徽标；右下：FPS + 最近帧时间(mono)。
- 断流占位：灰化最近帧 + 状态徽标 + "最近帧 HH:MM:SS"；连接/重连用骨架闪烁。
- 选中/放大：2px `accent` 描边；一级报警来源格：2px 级别色脉冲描边。
- 关键规则：letterbox 黑边不得裁剪画面内容；不叠加调试框（除 P5）。

### 7.6 关键状态条 StatusStrip

- 横向 7 项：受电弓、轮轨、车门、摄像头、AI、录像、存储。每项 = 图标 + 名称(caption) + 值(label)。
- 正常：`ok` 色点 + 静默；异常：`*_bg` 底色块 + 级别色 + 形状 + 文字，可点击进详情（按角色）。

### 7.7 时间轴 Timeline（P3）

- 轨道高 32px，`surface_elev` 底；连续录像为 `accent` 低饱和段；报警区段 3px 级别色 + 半透明 tint，可点选。
- 录像缺口：斜纹留白 + tooltip "录像缺失"。
- 游标：2px 白线 + 顶部时间(mono)；关键帧缩略图条位于轨道下方 64px 高。
- 播放控制：44px 目标，含播放/暂停、倍速、-30s/报警时刻/+30s/+60s。

### 7.8 表格/列表 Row

- 行高 48px；斑马纹不使用，用 1px `border` 分隔；悬停 `surface_hover`；选中左侧 3px `accent`。
- 级别列用徽标；确认状态用 chip；操作列靠右。
- 键盘：上下移动焦点，Enter 打开，空格确认。

### 7.9 空 / 加载 / 失败 / 恢复状态

| 状态 | 视觉 |
|---|---|
| 空态 | 居中图标(48px, `text_muted`) + 说明(label) + 主操作按钮；如"暂无报警" |
| 加载中 | 骨架屏（`surface_hover` 微光，1.2s 循环）；视频格用转圈 + "连接中" |
| 失败 | `error` 图标 + 原因文字 + [重试]；不显示原始堆栈 |
| 恢复 | 顶部 3s 绿色 toast"已恢复：<对象>" + 状态徽标转 `ok`；不弹模态打断驾驶 |

### 7.10 模态 / 弹窗 / Toast

- 模态：`overlay_scrim` + `surface_elev` + radius 12 + elevation 3；标题 h1；按钮右对齐。
- 自动弹窗（受电弓/轮轨/车门异常）：非模态浮层（z=300），可拖动/关闭，默认停留在不遮挡前方中央的位置。
- Toast：右下角，宽 ≤360px，3~10s；一级报警不用 toast（用横幅）。

### 7.11 设备卡片 DeviceCard（NVR 等）

- 与维护页其它卡片同规格（`surface` 底、1px `border`、圆角 8）。
- 头部：图标(`server`) + 名称(label) + 集成状态徽标（§3.6）。
- 字段行：地址(mono)、协议(`protocol` 未知则 `—`)、通道映射（已知列表 monospace / `未配置` neutral chip）、最近探测时间(mono)。
- 未配置态：卡片正常渲染，通道区显示“未配置”，**不显示错误红**（未提供 ≠ 故障）；不提供“自动配置/修改 NVR”按钮。
- 可达性未知：显示“未核验”neutral，不写成“不可达”。

### 7.12 检测职责徽标 DetectionBadge

- 结构：图标(16px) + 文本(caption 12px)，底 `neutral_bg`，文字 `text_secondary`，圆角 pill。
- 取值来自摄像头注册表 `ai_profile`（交互方案 §7.3）：`前方障碍/人员`、`受电弓三状态`、`轮轨`、`车门`、`广角·无检测`。
- “广角·无检测”使用更低对比度的 `text_muted`，明确表示该路不做识别，避免与检测路混淆。
- 位置：P4 全摄像头页每格左下角；P6 摄像头卡片内；不得进入司机 P1 主画面（保持驾驶界面简洁）。

## 8. 页面视觉与状态设计

页面示意见 `docs/hmi/mockups/`（1920×1080，手绘 SVG，非运行截图）。

### 8.1 P1 实时监控

- 示意：`p1_realtime_normal.svg`、`p1_realtime_alarm_l1.svg`、`p1_stream_states.svg`
- 结构：顶部 48px 全局状态条 → 三联（左 26% / 前 48% / 右 26%，前方面积最大）→ 64px 关键状态条 → 64px 当前报警条。
- 正常：三联画面 + 状态条全 `ok`；报警条区显示"暂无报警"空态。
- 顶部模式位：显示 `可见光`（neutral chip）+ `红外未接入`（`text_disabled`），无可交互模式控件（§3.6）。
- 一级报警：报警横幅实红常驻置顶，来源格脉冲描边，前方画面仍完整可见。
- 失败/降级：受影响格显示状态占位（见 7.5）；状态条对应项转色。
- 司机视图：无调试框、无参数、无日志。

### 8.2 P2 报警中心

- 示意：`p2_alarm_center.svg`
- 顶部筛选（日期/时间段/摄像头/类型/级别/确认状态）+ 批量确认；列表按级别→时间降序。
- 级别徽标列 + 录像可用性列；空态"暂无符合条件报警"+[清除筛选]。
- 确认交互：行内按钮，确认后行描边转 `border`，操作结果 3s toast。

### 8.3 P3 历史录像

- 示意：`p3_replay.svg`
- 上：日期/摄像头 + 三联同步开关；中：回放画面（前方报警默认左/前/右三画面）；下：时间轴 + 关键帧 + 播放控制；右：事件详情栏。
- 报警区段显著色标；缺口斜纹；录像不可用事件在详情栏黄条标注。

### 8.4 P4 全摄像头

- 示意：`p4_all_cameras.svg`
- 3×2 网格，每格 CameraTile；断流格保留位置不重排；顶部"6 路 / 在线 N"汇总。
- 适用于设备检查，不承担主驾驶视野。

### 8.5 P5 AI 调试

- 示意：`p5_ai_debug.svg`
- 主画面可叠加检测框/ROI/置信度/距离；右侧指标面板（FPS、延迟、模型版本、最近结果时间）。
- 调试叠加用高对比描边（框 `#00E5FF`，ROI 虚线 `#FFD400`），避免与报警红混淆。
- 权限：仅维护/研发/管理员；司机不可见。所有叠加默认关闭。

### 8.6 P6 设备维护

- 示意：`p6_maintenance.svg`
- 分区卡片：摄像头（在线/码流/帧率/最近帧/质量）、AI、录像与存储、网络与温度、云台、日志、NVR。
- NVR 卡（`192.168.1.4`）：显示登记/可达状态与通道映射；未提供时显示“未配置”（neutral），不提供自动改 NVR 配置入口（§7.11）。
- 云台卡显示目标值 vs 实际值与容差校验结果；提供[一键归位][重调前方预置位]。
- 异常项用状态徽标 + 可展开详情；操作确认用模态二次确认，结果写日志。

## 9. 布局与适配规则

- 主档 1920×1080，最低 1280×720；按比例缩放，主导航位置不重排。
- P0 元素在最低档不滚动即可见。
- 三联在任何档位保持"左-前-右"横向顺序，不改为上下堆叠。
- 文本放大/长文本：使用换行与省略；不挤压相邻控件；数字列固定宽度用等宽字体。
- 输入方式：触控 + 鼠标 + 键盘（Tab/Shift-Tab/Enter/Esc/方向键）均可用；悬停信息不得承载关键唯一信息。

## 10. 可访问性与驾驶安全

- 对比度：正文 ≥4.5:1，一级报警实底白字 5.66:1，关键警报色 ≥4.5:1（见 3.2/3.4）。
- 颜色非唯一编码（级别=形状+文字+颜色；状态=字形+文字+颜色）。
- 闪烁/脉冲 ≤3Hz，默认 1.5Hz；尊重系统"减少动态"设置。
- 触控目标 ≥44×44px；按钮间距 ≥8px。
- 焦点环始终可见（2px `focus_ring` + 光晕）；焦点顺序：顶部状态条 → 主画面 → 关键状态 → 报警条。
- 一级报警不可被静音为"无视觉"；静音仅关闭声音，视觉与横幅保留。
- 司机页不出现调试框/参数/日志；P5 与配置入口对司机不渲染。

## 12. 实现规则（供 desktop_app_implementation）

1. 所有颜色、字号、间距、圆角、状态色从 `design_tokens.yaml` 读取，不得硬编码。
2. 报警级别与流状态必须同时渲染"形状字形 + 文字 + 颜色"。
3. 非在线视频格必须渲染占位层与最近帧时间戳，禁止旧帧冒充实时。
4. 司机角色下 P5/配置入口不渲染；受限页显示无权限说明。
5. 浮层遵循 z-index 令牌；报警横幅不得覆盖前方主画面中央区。
6. 焦点环、触控目标尺寸、对比度按 §10 固化，不得因实现便利降低。

## 13. 待用户验证的问题（不由本设计单方面决定）

- V-01 实际车载屏尺寸、分辨率与是否触控（影响字号档与触控目标下限）。
- V-02 司机室环境光/眩光表现，深色主题是否满足现场可读性（需现场走查）。

- V-04 车牌/雨雪/夜间等场景下报警色与画面叠加的可辨识度。
- V-05 是否需要高对比/大字号"驾驶模式"（无障碍增强）开关。
- V-06 车速是否可接入（PRD Q-04），决定顶部状态条最终字段。
- V-07 NVR `192.168.1.4` 的账户/协议/6 路通道映射未提供（交互方案 Q-NVR）：通道命名与是否作为回放来源待确认；确认前统一显示“未配置/未核验”，不虚构通道号；建议由用户在设备授权后现场核验。
