## 0. 交付边界与平台判定

### 0.1 平台判定（来自项目输入，不默认 Web）

证据：

- 现有程序 `code/main.cc` 用 OpenCV highgui 在本机 X11 显示（`cv::namedWindow` / `cv::imshow` / `waitKey`），运行命令为 `DISPLAY=:0 ./rknn_yolov8_seg_demo ...`（`README.md` §3）。
- 目标硬件是车载 RK3588（Ubuntu 22.04.5 aarch64 + 显示器/VNC），`README.md` §2.1。
- 本项目 Workflow 的下游实现节点是 `embedded_linux_engineer.desktop_app_design` / `desktop_app_implementation`，即**本地桌面应用**。
- 本次需求更新新增 NVR（`192.168.1.4`）登记与各摄像头检测职责，属数据来源与算法职责变化，不构成浏览器/服务端平台变化；NVR 仅作为设备与录像来源被 HMI 消费。

结论：本 HMI 是运行在列车 RK3588 车机上的**本地桌面应用（驱动/维护用）**，不是浏览器 Web 应用。因此：

- 本文件交付**交互方案**（信息架构、导航、页面状态、操作反馈、布局、可访问性、异常恢复、可检验结果），供视觉设计与桌面应用设计/实现消费。
- 本 capability **不产出桌面运行代码**；桌面技术任务（框架选型、视频渲染管线、进程/线程、IPC、数据库、打包）由 `embedded_linux_engineer.desktop_app_design` 产生。任务清单只列交互设计工作。
- 本 capability 不做部署，不做全系统验收。

### 0.2 研究声明（区分用户研究与专业判断）

- 本项目**未执行用户研究、未观察真实司机、未做现场可用性测试**。本文中"司机需要什么/如何操作"为基于 PRD 用户角色与功能需求的**专业推演**，不是观察到的研究结论。
- 所有"建议/推荐"字样为专业判断；PRD 中带编号的条目（UI-/ALM-/PLY-/HLT-/FWD-/PAN-/WHL-/DOOR-/MODE-/DATA-）为需求判据，不得被本设计改变。
- 涉及现场可用性与眩光、震动、戴手套操作的结论，列为"待现场走查验证"，不写成已确认事实。

### 0.3 本轮交付边界

- 交付：交互方案 + 交互设计任务清单。
- 不交付：视觉稿/配色终稿（归 `ui_visual_design`）、桌面代码、模型算法、部署与全系统验收。
- 设备与网络的实际可用状态：项目设备工具已禁用，本文**不假定任何物理测试已执行**；摄像机地址与编码参数沿用目录说明，标注为"配置基线，待现场核验"。

### 0.4 本期产品范围（6 路可见光 / 本期不含红外 / NVR 登记）

来源：Runtime 环境配置约束 + PRD §13 + `一些说明和要求.txt`。

- **本期接入且仅接入 6 路可见光**：前方（CAM-01）、左侧（CAM-02）、右侧（CAM-03）、车顶（CAM-04）、车底（CAM-05）、司机室（CAM-06）。**本期不接入红外**，不套用历史 7 路/8 路地址范围。
- 因此 PRD 中可见光/红外相关需求（MODE-001 自动切换、MODE-002 手动切换、MODE-003 切换迟滞、MODE-004 模式可见、PTZ-004 双光预置位、FWD-008 模式独立阈值）**在本期界面按“仅可见光/未接入”中性状态呈现**，不构成本期页面的可交互控件；待红外接入后由本方案增补，不删除需求编号。
- **NVR（`192.168.1.4`）已登记为设备**，但其账户、协议、管理入口与 6 路通道映射**未提供**：界面只显示“已登记 / 未配置”与可达状态，不虚构通道号、不自动修改 NVR 配置。NVR 在本期不替代已配置的 6 路直连相机；是否作为回放来源由配置决定（见 §7.2 `recording_source`）。
- 每路摄像头的**检测职责**（见 §7.3）来自 `一些说明和要求.txt` 第 11 条：车顶受电弓三状态、车底轮轨关系、司机室车门、车头前方障碍/人员、左右侧仅提供大视野不检测。界面按注册表的 `ai_enabled`/`ai_profile` 驱动，改配置不改界面代码。

## 2. 目标用户与任务

| 角色 | 主要任务 | 默认落地页 | 权限特征 |
|---|---|---|---|
| 司机 | 看前方/左右环境；接收并确认报警；一键查看报警录像 | 实时监控 | 可见实时监控、报警中心、历史回放；**默认无 AI 调试、无参数配置、无导出** |
| 检修/维护 | 看六路、校验云台、查设备状态与历史事件与录像 | 全摄像头 / 设备维护 | 可见全部页面；可云台归位、重连、导出（受配置） |
| 研发/调试 | 看检测框、ROI、距离、置信度、帧率、延迟、模型版本、原始录像 | AI 调试 | 可见 AI 调试；可切调试叠加层 |
| 管理员 | 摄像头参数、报警/录像策略、账户权限、系统配置 | 设备维护/设置 | 配置与导出权限 |

驾驶员核心任务链（来自 PRD 附录 B，作为交互主路径）：

1. 前方障碍报警：检测 → 进危险区 → 多帧确认 → 一级报警 → 红色提示/声音 → 自动事件与前后录像 → 司机确认 → 一键回放 → 事件保留。
2. 云台重启恢复：上电 → 归位/绝对位置初始化 → 调前方预置位 → 读实际角度/Zoom → 容差校验 →（可选）视觉校验 → 前方 AI READY。
3. 报警录像查看：列表选事件 → 查看录像 → 定位报警时间 → 前/左/右三联同步回放 → 关键帧/倍速/导出。

## 3. 信息架构与导航

### 3.1 页面集合（PRD §4.2）

| 页面 ID | 名称 | 用途 | 显式需求 |
|---|---|---|---|
| P1 | 实时监控 | 司机主页面：三联实时视野、关键状态、当前报警、快捷回放入口 | UI-001..006 |
| P2 | 报警中心 | 集中处理：当前/历史报警、级别、时间、来源、处理状态、查看录像 | ALM-001..006、PLY-006 |
| P3 | 历史录像 | 按时间/事件回放：时间轴、报警标记、片段、同步多路、导出 | PLY-001..008 |
| P4 | 全摄像头 | 六路同屏，设备检查 | T-01、HLT-001 |
| P5 | AI 调试 | 检测框、ROI、置信度、距离、帧率、延迟、模型版本 | PRD §4.2、研发角色 |
| P6 | 设备维护 | 摄像头在线、码流、云台位置、存储（含 NVR 登记与通道映射）、网络、温度、日志、重连 | HLT-001..007、PTZ-005 |

### 3.2 导航结构

- 单窗口应用，顶部**全局状态条**（UI-005）常驻所有页面：当前时间、车速（若可接入）、可见光/红外模式（MODE-004）、录像状态、AI 状态、系统健康。
- 一级导航为侧边/底部固定 6 项，按角色过滤可见项。
- 司机角色：P1/P2/P3；维护/研发/管理员：全部。权限不可见项不显示（而非禁用后仍可见），避免司机误入调试。
- 全局报警横幅（见 §6）悬浮于所有页面之上，不因页面切换消失。
- 返回路径：P3/P2 从 P1 进入时保留来源上下文（"返回实时监控"）；从报警卡片进入 P3 时锁定该报警相关摄像头与时间。

### 3.3 信息优先级

1. 一级报警与前方主画面（UI-003、ALM-003）。
2. 前方/左/右三联实时视野。
3. 关键状态区异常项（UI-004）。
4. 二级/三级报警与设备提示。
5. 调试与维护信息（仅对应页面/角色）。

## 4. 全局布局与响应式规则

### 4.1 目标显示档位

| 档位 | 分辨率 | 要求 |
|---|---|---|
| 主档 | 1920×1080 横屏 | 完整布局默认值 |
| 最低档 | 1280×720 横屏 | P0 信息不滚动即可见，三联不折叠隐藏 |

- 安全边距：四周 ≥24 px（1080 档）/ ≥16 px（720 档）。
- 布局按比例缩放，不重排主导航位置。
- 触控目标 ≥44×44 px（含间距）；同时支持鼠标与键盘。
- 不使用需要悬停才出现的司机关键信息（Hover-only 禁止用于报警/状态）。

### 4.2 P1 三联布局

```
┌───────────────────────── 顶部全局状态条 ─────────────────────────┐
│ 时间 | 车速 | 模式(可见光/红外) | 录像 | AI | 系统健康            │
├──────────────┬──────────────────────────────┬───────────────────┤
│  左侧 CAM-02 │        前方 CAM-01           │   右侧 CAM-03     │
│  (周身扩展)  │      (最大面积, 最高优先)     │   (周身扩展)      │
├──────────────┴──────────────────────────────┴───────────────────┤
│ 关键状态区: 受电弓 | 轮轨 | 车门 | 摄像头 | AI | 录像 | 存储       │
├─────────────────────────────────────────────────────────────────┤
│ 当前报警条(最高级优先) + [确认] [查看回放]   [警报复览入口]        │
└─────────────────────────────────────────────────────────────────┘
```

- UI-001/002：左-前-右三路视觉紧邻、统一高度与比例；允许几何校正/裁剪使画面连续，**不要求像素级全景拼接**。
- UI-003：前方画面始终面积最大；报警弹窗/横幅不得覆盖前方画面的中央可视区（可占用边缘或独立区域）。
- 三联画面在各档位保持"左-前-右"顺序，不因窄屏改为上下堆叠。

## 5. 页面状态与操作规格

> 通用状态取值见 §7。每个页面给出：可检验的进入条件、操作、反馈、异常。

### 5.1 P1 实时监控

- 进入条件：应用启动或切换至 P1。
- 显示：三联实时画面、关键状态区（UI-004）、当前报警条、快捷回放入口。
- 操作与反馈：
  - 点击某路画面：放大该路（不改变前方画面优先级；放大窗可关闭）。
  - 点击状态项：跳转对应详情（受电弓/轮轨/车门→P4 对应摄像头；摄像头/AI→P6 或 P5，按角色）。
  - 点击报警条[确认]：处理状态变为已确认，**不删除事件**（ALM-004）。
  - 点击报警条[查看回放]：进入 P3 并定位到该报警时刻（PLY-001）。
- 异常：
  - 某路断流：该格显示"重连中"占位（最近一帧灰化 + 时间戳 + 状态），**不得把旧帧当作实时画面**（非功能需求"网络异常"）。
  - 一级报警：红色横幅 + 声音，常驻至确认。

### 5.2 P2 报警中心

- 列表字段：级别、类型、发生时间、来源摄像头、简要描述、处理状态（未确认/已确认）、录像可用性。
- 默认排序：级别降序 → 时间降序（UI-003、ALM-003：前方/轮轨一级最先）。
- 操作：确认/已知悉、批量确认、查看录像、查看快照、按条件筛选。
- 筛选维度（PLY-006）：日期、时间段、摄像头、报警类型、报警级别、确认状态。
- 反馈：确认后行状态即时变化并写维护/操作日志（HLT-007）；无结果时显示空态与清除筛选入口。
- 异常：录像缺失时该行显式标记"录像不完整/不可用"，不静默（PLY-008）。

### 5.3 P3 历史录像

- 上部：日期与摄像头选择；从报警详情进入时自动锁定相关摄像头（PRD §9.2）。
- 中部：回放画面；前方报警默认左/前/右三联同步（PLY-005）。
- 下部：时间轴 + 报警区段显著色标 + 关键帧缩略图 + 播放/暂停/倍速/前后跳转。
- 必备操作：一键跳报警前 30s、报警时刻、报警后 30s/60s（PLY-004）。
- 右侧栏：事件详情（时间、类型、级别、目标距离、置信度、处理状态、备注）。
- 异常：时间轴对录像缺口（gap）显式留白/虚线标记；录像服务异常或容量不足时事件标注不可用（PLY-008）。
- 权限：导出仅授权角色可见（PLY-007、非功能需求"权限"）。

### 5.4 P4 全摄像头

- 六路同屏网格（2×3 或 3×2），每格：画面、摄像头名/位置、连接状态角标、实时 FPS、最近一帧时间。
- 断流/冻结格子保留位置并显示状态，不重排（避免操作时跳位）。
- 点击进入单路详情（含码流、分辨率、PTZ 位置，按角色）。
- 目的为设备检查（T-01、HLT-001），不承担驾驶主视野职责。

### 5.5 P5 AI 调试

- 显示：检测框、轨道 ROI、置信度、目标距离、帧率、端到端延迟、模型版本、最近结果时间（HLT-004、PRD §4.2）。
- 可切换调试叠加层开关（框/ROI/文字/掩码）。
- 隔离要求：司机视图默认不含本页，且任一调试叠加层默认关闭（非功能需求"UI可读性"）。
- 权限：仅研发/调试/维护可见。

### 5.6 P6 设备维护

- 摄像头：在线/码流/帧率/最近一帧时间（HLT-001）、画面冻结（HLT-002）、画面质量（过暗/过曝/遮挡/模糊，HLT-003）。
- AI：状态、模型版本、推理 FPS、最近结果时间（HLT-004）。
- 录像：进程状态、剩余容量、写入异常、文件完整性（HLT-005）；容量低于阈值提前告警（DATA-003）。
- 网络/系统：NPU/CPU 负载、温度、网络错误计数。
- 云台：Pan/Tilt/Zoom 实际值与目标值、容差校验结果、一键归位、重新调用前方预置位（PTZ-002/005）。
- NVR（`192.168.1.4`）：显示“已登记 / 未配置 / 可达 / 不可达”；已提供地址但账户、协议与 6 路通道映射未知时，通道列显示“未配置”，不显示猜测通道号；界面不提供自动修改 NVR 配置的入口。
- 重连：支持手动重连；自动重连达阈值升级为设备报警（HLT-006）。
- 维护日志：重启、归位、参数变更、模型升级、导出，记录时间/用户/结果（HLT-007）。

## 6. 报警交互规范

### 6.1 级别与编码（ALM-002）

| 级别 | 颜色 | 图形 | 声音 | 默认动作 |
|---|---|---|---|---|
| 一级 | 红 | 实心三角/边框脉冲（≤3Hz） | 报警声，直到确认 | 全局提示 + 自动记录报警录像 + 一键回放 |
| 二级 | 橙 | 实心圆 | 短提示音 | 对应摄像头预览 + 事件录像 |
| 三级 | 黄 | 描边圆 | 无/可选轻提示 | 设备提示 |

颜色**不得作为唯一编码**：同时使用图标形状 + 文字级别 + 摄像头名（可访问性）。

### 6.2 提示与确认

- ALM-001：内容至少含类型、发生时间、摄像头、级别、简要描述。
- ALM-004：确认只改处理状态，不删除事件；确认后一级声音停止，横幅降级为可关闭。
- ALM-005：同一跟踪目标在设定时间窗内不重复刷屏；更新同一事件的距离/状态/持续时间。
- ALM-006：每事件至少一张关键帧截图，并记录算法类型、模型版本、置信度、目标距离。

### 6.3 异常自动弹出（UI-006）

- 触发：车顶（受电弓）、车底（轮轨）、车门异常。
- 形式：弹出对应摄像头较大预览，提供[关闭]/[详情]。
- 约束：不得完全遮挡前方主画面；同一时刻最多一个自动弹窗；一级前方报警优先于该弹窗。

### 6.4 建议报警映射（PRD §8.2，保持不变）

前方轨道人员/障碍物→一级；轮轨明显异常/疑似脱轨→一级；受电弓异常→二级；车门未关严→二级；前方主摄像头离线/冻结→二级（前方 AI 切不可用）；侧视摄像头离线→三级。

## 7. 状态模型与数据契约（供视觉/桌面实现消费）

### 7.1 摄像头连接状态机

```
OFFLINE ──启动/重连──► CONNECTING ──首帧──► LIVE
   ▲                        │失败             │ 超时无新帧(冻结)
   │                        ▼                 ▼
   └──── 达重连阈值 ◄── RECONNECTING ◄── FROZEN / DEGRADED
```

取值与显示：

| 状态 | 显示 | 是否计为可用 |
|---|---|---|
| CONNECTING | "连接中…" + 转圈 | 否 |
| LIVE | 实时画面 | 是 |
| FROZEN | 灰化最近帧 + 时间戳 + "画面冻结" | 否 |
| OFFLINE | "离线" + 图标 | 否 |
| RECONNECTING | "重连中…" + 已重连次数 | 否 |
| DEGRADED | 实时画面 + 质量角标（暗/过曝/遮挡/模糊） | 是（降级） |

硬约束：非 LIVE 状态下**禁止**把旧帧呈现为实时；必须展示状态占位与最近帧时间（非功能需求"网络异常"）。

### 7.2 交互所需数据字段（实现须提供）

- 摄像头注册表：`id, name, position(primary|left|right|roof|underfloor|cab), rtsp_url, ai_enabled, ai_profile`。
- 摄像头运行时：`state, fps, bitrate, resolution, last_frame_ts, quality_flags, reconnect_count`。
- AI 模块：`status, model_version, fps, latency_ms, last_result_ts`。
- 报警事件：`id, level(1|2|3), type, source_cam, ts, track_id, confidence, distance_m, description, ack_state, record_available, snapshot_ref`。
- 录像：`continuous_segments, critical_segments, gaps, storage_free, storage_total, recorder_status, recording_source(local|nvr|both)`。
- NVR：`registered, management_reachable, channel_mapping(已知通道列表|未配置), protocol, last_probe_ts`；本期 `channel_mapping` 未提供，界面按“未配置”呈现。
- 设备：`npu_load, cpu, temp_c, net_errors, disk`。
- 云台：`pan, tilt, zoom, preset, homing_state, tolerance_ok`。
- 日志：`ts, user, action, target, result`。

> 字段为交互契约，具体存储/接口形式由 `desktop_app_design` 决定。

## 9. 可访问性与驾驶安全约束

- 对比度：文本/关键图标对背景 ≥4.5:1；报警横幅 ≥7:1。
- 颜色非唯一编码：级别 = 颜色 + 形状 + 文字。
- 闪烁/脉冲频率 ≤3Hz，避免光敏与驾驶分心。
- 触控目标 ≥44px；支持戴手套的粗操作（关键按钮加大且间距足够）。
- 键盘：Tab 焦点顺序 = 顶部状态条 → 主画面 → 关键状态 → 报警条；Esc 关闭弹窗。
- 字体：主状态/报警文本在 1280×720 档不低于 16px 等效，一级报警标题不低于 24px 等效。
- 声音：报警声与视觉提示并存；提供静音/音量控制但**一级报警不可被静音为无视觉**。
- 司机页无滚动条依赖：P0 信息在最低档一屏可见。

## 10. 异常与恢复交互

| 场景 | 交互行为 |
|---|---|
| 摄像头断流 | 该格进 RECONNECTING，显示已重连次数与最近帧时间；达阈值升级设备报警（HLT-006） |
| 画面冻结 | 识别为"画面冻结/视频异常"（HLT-002），灰化并标注，不计可用 |
| 前方主摄像头离线/冻结 | 前方 AI 状态切"不可用"，二级设备报警（PRD §8.2） |
| AI 进程退出 | 状态区 AI 项转异常；相关检测类报警标注"AI 不可用"，不静默 |
| 录像服务异常/容量不足 | 事件显式标记"录像不完整/不可用"（PLY-008）；存储低于阈值提前告警（DATA-003） |
| 云台归位失败/超差 | 设备维护页显示容差校验失败，前方 AI 进入 NOT_READY，提示重试归位（PTZ-002） |
| 断电/重启 | 自动恢复摄像头连接、录像、AI、云台前方预置位，并显示恢复进度（非功能需求"可恢复性"） |
| 网络抖动 | 记录丢流时间；不使用旧帧冒充实时；恢复后正常刷新 |
| 单路非关键摄像头异常 | 不导致整体退出，其余页面继续可用（非功能需求"可靠性"） |

## 11. 可检验结果（供视觉设计与测试使用）

1. 在 1920×1080 与 1280×720 两档，P1 的 P0 元素（三联画面、关键状态区、当前报警条、顶部状态条）无需滚动即可见。
2. 一级前方报警发生时，前方主画面中央可视区未被任何弹窗/横幅完全遮挡。
3. 每个报警事件卡片都提供"查看回放"入口；点击后进入 P3 并定位到该报警时刻。
4. P3 时间轴上报警区段以显著颜色标记，且提供 -30s / 报警时刻 / +30s / +60s 四个跳转。
5. 前方障碍报警在 P3 默认呈现左/前/右三路同一时间轴同步播放。
6. 任一非 LIVE 摄像头格子显示状态占位与最近帧时间戳，且不呈现旧帧为实时。
7. 报警级别同时具备颜色、形状/图标、文字三种编码；关闭颜色仍可区分级别。
8. 报警内容包含类型、时间、摄像头、级别、描述五项；一级报警持续到确认，确认后事件仍可检索。
9. 录像缺失的事件在列表与详情显式标记"录像不完整/不可用"。
10. 司机角色下不渲染 AI 调试与配置入口；直接导航到受限页显示无权限说明。
11. 云台归位/预置位调用后显示目标值与实际值及容差校验结果。
12. 六路摄像头在 P4 同屏，各显示连接状态、FPS、最近一帧时间。
13. 设备维护页显示 NVR 登记与可达状态；通道映射未提供时显示“未配置”而非猜测通道号，且界面不提供自动修改 NVR 配置的入口。
14. 本期界面不出现可交互的红外/模式切换控件；模式位显示为“可见光（本期）/红外未接入”中性状态。

## 12. 待确认事项（来自 PRD §14，影响交互但不由本设计决定）

- Q-01 前方光学通道形态 → **本期不适用（只接可见光）**，界面不提供模式切换控件；红外接入后再影响模式/预置位交互。
- Q-03 红外补光功率与有效距离 → **本期不适用**，界面不呈现红外指标。
- Q-04 车速/里程/GPS 是否可读 → 影响顶部状态条是否显示车速与风险分级。
- Q-05 车门采用视觉/门磁/融合 → 影响车门状态来源与是否显示门磁输入。
- Q-06 录像保留天数/容量/导出方式 → 影响 P3 与 P6 存储展示与导出交互。
- Q-07 报警声方式/外部蜂鸣器 → 影响声音提示通道选择。
- Q-08 是否量化 TTC → 影响是否展示碰撞时间指标。
- Q-NVR NVR 账户/协议/6 路通道映射 → 决定 NVR 是否作为回放来源与通道命名；未提供时按“未配置”呈现，不影响 6 路直连相机。

以上未确认项在界面中以"不可用/未接入"状态呈现，不虚构数据。
